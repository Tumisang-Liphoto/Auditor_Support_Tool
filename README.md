# Auditor Support Tool

The Auditor Support Tool is a modular Windows desktop application intended to
support data-enabled audit work.

The application will enable auditors to:

- create and preserve audit engagements;
- import and profile structured audit data;
- map source fields to standard audit data models;
- execute configurable audit procedures;
- identify transactions and risk areas requiring further investigation;
- document investigation notes and preliminary statuses;
- generate audit working papers and exception reports;
- access an approved browser-based local AI service;
- update the application through public GitHub releases.

## Initial Pilot

The first implementation will support:

- Financial Audit;
- General Ledger analysis;
- Excel `.xlsx` and CSV source files;
- local offline analysis;
- Windows 10 and Windows 11.

Financial Audit is the first intentionally selected audit domain. The underlying
platform is being designed to support additional audit domains in future.

## Project Status

Current version: `0.1.0`

Development status: Pre-alpha requirements and application foundation.

## Security Notice

Do not commit real audit data, engagement files, reports, credentials, internal
network addresses or confidential configuration to this public repository.
